# HANI-EL GOLD — Private Maison V5

## هدف این نسخه

تکمیل طراحی و تعاملات فرانت‌اند موبایل و دسکتاپ بر پایه طرح تأییدشده «Quiet Ultra Luxury» و حفظ شش بخش اصلی صفحه نخست. این بسته **فروشگاه عملیاتی نیست**: داده‌های تصویری نمونه‌اند و قیمت، موجودی، فاکتور و سفارش واقعی به سرویس متصل نشده‌اند.

| `#/favorites` | محصولات ذخیره‌شده در مرورگر |
| `#/cart` | سبد آزمایشی و تغییر تعداد/حذف |
| `#/checkout` | ورود و اعتبارسنجی اطلاعات تحویل، بازبینی، بازگشت به ویرایش؛ **بدون ثبت سفارش** |

| `#/guide` | راهنمای خرید |
| `#/faq` | سؤالات متداول |

| `#/privacy` | توضیحات حریم خصوصی نسخه آزمایشی و جایگاه سیاست نهایی |

## نکات فنی

- HTML، CSS و JavaScript مستقل، فارسی RTL، موبایل‌فرست و دو تم روشن/تاریک.
- چهار وزن اصلی فونت یکان‌بخ به درخواست مالک دوباره در CSS تعبیه شده‌اند؛ راهنمای `../docs/FONTS_FA.md` را ببینید؛ تصاویر و لوگوهای رسمی پروژه در `assets`.
- انیمیشن‌های محدود با پشتیبانی `prefers-reduced-motion`، تب‌ها و لایه‌های دارای تعامل کیبورد، حالت‌های خالی و خطای کاتالوگ.
- حالت آزمایشی فقط علاقه‌مندی‌ها، تعداد سبد و انتخاب تم را در localStorage نگه می‌دارد. **داده‌های فرم تماس، نشانی و تکمیل سفارش دائماً ذخیره نمی‌شوند و در حالت دمو به سرور ارسال نمی‌شوند.**
- در کاتالوگ نمونه‌های مفهومی نشان داده می‌شوند؛ قیمت و موجودی واقعی عمداً خالی می‌ماند.
- با تنظیم `window.HANIEL_CONFIG.apiBaseUrl` پیش از اجرای `app.js` کاتالوگ از سرور بارگذاری می‌شود؛ جزئیات قرارداد API در `docs/BACKEND_CONTRACT_FA.md` است.
- کد در حال حاضر یک SPA با آدرس‌های hash است. برای انتشار نهایی، مهاجرت مسیرها به SSR/SSG یا تنظیم درست مسیریابی و SEO توصیه می‌شود؛ این مرحله با ساخت بک‌اند و زیرساخت انتشار تکمیل می‌شود.

## اجرا

فایل مستقل `HANI-EL-GOLD_V5_Interactive_Demo.html` شامل CSS، JS و تصاویر است و مستقیم از داخل مرورگر قابل بازشدن است. برای اجرای سورس پوشه‌ای از داخل پروژه:

```bash
python -m http.server 8000
```

سپس به `http://localhost:8000` بروید.

## آنچه برای بک‌اند باقی مانده است

داده و تصاویر واقعی محصول، ادمین/مدیریت کاتالوگ و موجودی، قیمت لحظه‌ای و استعلام نهایی، محاسبه فاکتور و مالیات معتبر، امنیت و حساب مشتری، آدرس‌های ذخیره‌شده، سرویس پیامک و پشتیبانی، سفارش/پیگیری، ارسال و درگاه پرداخت، قوانین/شرایط رسمی، و راه‌اندازی/SEO/مانیتورینگ.

**نکته امنیتی:** مبلغ نهایی یا موجودی نباید از محاسبه سمت مرورگر معتبر شناخته شود. بک‌اند باید در لحظه سفارش `quote` معتبر و قابل انقضا صادر کند و پرداخت و ثبت سفارش را سمت سرور تأیید نماید.
