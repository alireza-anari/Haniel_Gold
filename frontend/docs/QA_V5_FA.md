# گزارش بررسی رابط V5

## انجام‌شده

- اعتبارسنجی کد JavaScript (`node --check`).
- اجرای HTML مستقل با فونت ارسالی و تصاویر داخل فایل.
- بررسی ۱۳ مسیر در مرورگر و شش اندازه صفحه: ۳۲۰، ۳۶۰، ۳۹۰، ۷۶۸، ۱۰۲۴، ۱۴۴۰ پیکسل.
- نبود بیرون‌زدگی افقی در صفحات بررسی‌شده.
- عملکرد منو، تغییر تم، رفتن از فهرست به محصول، افزودن به سبد آزمایشی.
- فرم تکمیل خرید: اعتبارسنجی، بازبینی، ویرایش.
- فرم نشانی: خطا، پیش‌نمایش، ویرایش و پاک‌کردن.
- فرم تماس: اعتبارسنجی و اطلاع واضح از ارسال‌نشدن در حالت دمو.
- دریافت کاتالوگ از API آزمایشی با یک محصول و رندر صفحه اصلی/فهرست/جزئیات بدون خطا.
- بدون خطای صفحه JavaScript در سناریوهای فوق.

## نیازمند آزمون هنگام اتصال واقعی

- قرارداد و خطاهای واقعی API، نشست و ورود پیامکی، سبد سروری و قیمت معتبر، سفارش و پرداخت.
- بررسی مرورگر Safari در گوشی واقعی، اندرویدهای گوناگون و شبکه ضعیف.
- امنیت، دسترس‌پذیری کامل با صفحه‌خوان، performance budgets و Core Web Vitals تولیدی.
- SEO و راه‌اندازی مسیرهای بدون hash در سایت عملیاتی.
