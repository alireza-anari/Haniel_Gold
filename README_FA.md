# HANI-EL GOLD — ویترین Cloudflare و پنل مدیریت

## معماری فعال
- **فرانت‌اند:** `frontend/`، فارسی RTL، طراحی V5، حالت روشن و تاریک.
- **API:** Cloudflare Pages Functions در `functions/`؛ مسیر هم‌دامنه `/api/v1`.
- **داده‌ها:** Cloudflare D1 با طرح پایه `cloudflare/schema.sql` و مهاجرت‌های بعدی.
- **تصاویر محصولات:** Workers KV با Binding دقیق `MEDIA_KV`؛ برای مسیر فعلی R2 یا کارت بانکی لازم نیست.
- **پنل مدیریت:** `/admin` یا `/admin.html`. محصولات، دسته‌بندی، تصاویر، مشخصات، اجرت و سود هر محصول از همین پنل ثبت می‌شوند.
- **کد Django/PostgreSQL در `backend/`** برای حفظ تاریخچه/بازگشت نگه داشته شده و runtime فعلی Pages نیست.

## شیوه کار کاتالوگ
1. مدیر دسته‌بندی را ثبت می‌کند.
2. مدیر محصول را با مشخصات واقعی و عکس واقعی در پنل وارد می‌کند؛ محصول تا بررسی کامل به‌صورت پیش‌نویس می‌ماند.
3. پس از تکمیل اطلاعات و وجود نرخ معتبر Servix و سیاست مالی تأییدشده، قیمت عمومی محاسبه و نمایش داده می‌شود. قیمت منقضی یا نامعتبر نباید جایگزین‌سازی یا حدس زده شود.
4. مشتری سبد را به‌عنوان **درخواست بررسی خرید** ارسال می‌کند، نه پرداخت قطعی. مدیر درخواست را می‌بیند، قیمت و موجودی را بررسی می‌کند و وضعیت را به‌روز می‌کند.
5. **ورود محصول از تلگرام و Webhook ورودی بازنشسته است.** ورود و انتشار محصولات فقط از پنل ادمین انجام می‌شود؛ اعلان خروجی استعلام خرید با ربات تلگرام، پس از تنظیم امن توکن و شناسه مدیران، قابلیت مستقلی است.

## وضعیت انتشار و محدودیت‌ها
این نسخه هنوز Staging است. ثبت درخواست وابسته به تنظیمات امنیتی Turnstile، ساعات کاری تهران و تقویم تعطیلات بازبینی‌شده است. کد فعلی درگاه پرداخت، پیامک SMS.ir، OTP مشتری، فاکتور، ارسال و چرخه کامل سفارش را فعال نمی‌کند؛ بنابراین تا زمان اتصال و تست واقعی این خدمات، سایت را فروشگاه پرداخت آنلاین تلقی نکن.

دسترسی پایدار از اپراتورهای داخل ایران، دامنه نهایی، آزمون end-to-end، بکاپ و سیاست‌های حقوقی/حریم خصوصی نیز باید پیش از انتشار تجاری تأیید شوند.

## فایل‌های مهم
- `cloudflare/schema.sql`: طرح پایه D1.
- `cloudflare/0002_gold_pricing.sql`: جداول نرخ و سیاست قیمت‌گذاری.
- `cloudflare/0003_inquiry_telegram.sql`: مهاجرت تاریخی که جداول درخواست و جدول قدیمی پیش‌نویس تلگرام را ایجاد می‌کرد.
- `cloudflare/0004_remove_telegram.sql`: حذف جدول قدیمی تلگرام بدون حذف درخواست‌های خرید.
- `cloudflare/0005_inquiry_notifications.sql`: ثبت وضعیت اعلان خروجی استعلام برای هر مدیر؛ شامل هیچ Secret یا داده مشتری نیست.
- `docs/CLOUDFLARE_FULLSTACK_FA.md`: راه‌اندازی Pages، D1 و KV.
- `docs/PURCHASE_INQUIRIES_FA.md`: فرآیند درخواست خرید و مدیریت دستی کاتالوگ.

## بررسی کیفیت
CI در GitHub Actions، بررسی نحوی JavaScript، تست‌های API و کاتالوگ، تست‌های قیمت‌گذاری، و تست‌های Django موجود در پوشه legacy را اجرا می‌کند. سبز بودن CI به‌تنهایی معادل آمادگی فروش واقعی نیست.
