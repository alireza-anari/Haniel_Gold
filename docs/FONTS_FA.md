# فونت یکان‌بخ

به درخواست صریح مالک پروژه، چهار وزن اصلی ۳۰۰، ۴۰۰، ۶۰۰ و ۷۰۰ یکان‌بخ از ZIP اولیه، بدون تغییر داده فونت، دوباره داخل `frontend/styles.css` تعبیه شدند. نیازی به فایل فونت جداگانه یا مسیر private-fonts نیست.

این فونت‌ها همراه CSS در مخزن Public قابل دریافت هستند. درخواست بازگردانی مالک، مدرک مجوز انتشار عمومی فونت محسوب نمی‌شود؛ مجوز انتشار عمومی در فایل‌های ارائه‌شده موجود نیست.

اسکنر، فونت تعبیه‌شده در همین فایل CSS را به‌عنوان استثنای صریح مالک می‌پذیرد؛ محدودیت فایل‌های مستقل فونت و بررسی اسرار همچنان برقرار است.
