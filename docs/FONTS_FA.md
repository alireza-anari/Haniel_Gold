# فونت یکان‌بخ

به درخواست صریح مالک پروژه، چهار وزن اصلی ۳۰۰، ۴۰۰، ۶۰۰ و ۷۰۰ یکان‌بخ از ZIP اولیه، بدون تغییر داده فونت، در فایل مشترک `frontend/brand-fonts.css` نگهداری می‌شوند. ویترین و پنل ادمین همین فایل را بارگذاری می‌کنند تا تایپوگرافی در هر دو بخش یکسان باشد.

این فونت‌ها همراه CSS در مخزن Public قابل دریافت هستند. درخواست بازگردانی مالک، مدرک مجوز انتشار عمومی فونت محسوب نمی‌شود؛ مجوز انتشار عمومی در فایل‌های ارائه‌شده موجود نیست.

اسکنر مخزن، تعبیه این چهار فونت را فقط در `frontend/brand-fonts.css` به‌عنوان استثنای صریح مالک می‌پذیرد؛ محدودیت فایل‌های مستقل فونت و بررسی اسرار همچنان برقرار است.
