# فونت دارای مجوز

چهار فونت تعبیه‌شده یکان‌بخ از CSS عمومی حذف شدند؛ مجوز انتشار عمومی ارائه نشده است. لوگوها و تصاویر تغییر نکرده‌اند.

فقط پس از تأیید مجوز استفاده وب، فایل‌های WOFF2 دارای مجوز را مستقیماً روی سرور در `frontend/private-fonts/` قرار دهید. نام‌ها: `yekan-bakh-300.woff2`, `yekan-bakh-400.woff2`, `yekan-bakh-600.woff2`, `yekan-bakh-700.woff2`. این مسیر و فایل‌های فونت در gitignore هستند. Caddy مسیر `/private-fonts/` را سرو می‌کند؛ بدون فونت، fallback سیستم فعال است. عمومی نبودن فایل در Git به معنی خصوصی بودن فایل سرو‌شده در وب نیست؛ مجوز وب باید معتبر باشد.
