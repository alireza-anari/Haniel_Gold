# چک‌لیست انتشار

1. تغییرات UI را در branch جدا توسعه دهید، PR ایجاد کنید و CI را بررسی کنید.
2. بررسی کنید فایل `.env`، توکن Servix، کوکی نشست، فاکتور/اطلاعات مشتری داخل Git وارد نشده باشد.
3. از دیتابیس production بکاپ بگیرید و صحت فایل را بررسی کنید.
4. سرویس‌ها را با Docker Compose به‌روزرسانی کنید.
5. `/api/v1/ready`, `/`, `/admin/`, `/api/v1/catalog/products` و تم‌های روشن و تاریک را تست کنید.
6. اگر خطای نرخ، موجودی یا پرداخت رخ داد، سفارش جدید را متوقف کنید؛ هرگز از نرخ تخمینی یا کش منقضی‌شده استفاده نکنید.
7. سابقه deploy شامل SHA commit را ثبت کنید؛ تغییرات حساس مالی نیازمند review مجزا هستند.
